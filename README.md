## 📋 Overview

**NexaCard** redefines the digital business card. It's not just a vCard website—it's an **Interactive Identity Hub** where contact information, social profiles, portfolio, QR code, and micro-interactions converge into a premium, memorable experience.

Inspired by Apple Vision Pro aesthetics and luxury card design, NexaCard uses a **Liquid Crystal Interface** with frosted glass, morphing blobs, and floating light orbs to create a digital identity that stands out.

### Why NexaCard?

| Traditional vCard | NexaCard |
|---|---|
| Static contact info | Interactive 3D business card |
| Plain link lists | Animated social hub with tooltips |
| Basic QR image | Dynamic QR with scan animation |
| No analytics | Built-in visitor & engagement dashboard |
| Generic design | Liquid Crystal premium UI |
| No customization | Dark/light mode, accent colors, language selector |
| Single page | Multi-section interactive experience |

## ✨ Features

### 🎬 Splash Experience
- **Crystal logo formation** animation
- **Rotating loading ring** with gradient colors
- **Gradient wave** animation at bottom
- Auto-transition to main content after 2.2 seconds

### 💳 Main Digital Card
- **3D perspective tilt** on mouse hover
- **Animated profile ring** with pulsing gradient glow
- Displays: Photo, Name, Role, Company, Bio
- **Status badge** with pulsing dot (Available/Busy)
- Location indicator
- Action buttons: Save Contact, Share Card, Call, Email, WhatsApp
- **Magnetic button** hover effects

### 🌐 Social Hub
- **Animated icon grid** with 10 social platforms
- Supported: GitHub, LinkedIn, Twitter, Instagram, Facebook, YouTube, Telegram, Discord, Medium, Personal Website
- **Hover expansion** with glow effect
- **Quick preview tooltip** on each icon
- Smooth scale animations

### ⚡ Services
- Grid layout showcasing professional services
- Glass card hover effects
- Custom icons for each service category

### 🎨 Portfolio Showcase
- **Horizontal scroll slider** with snap points
- Each project card shows: Icon, Title, Description, Technology tags
- **Glass lift animation** on hover
- Smooth touch scrolling on mobile

### 📱 QR Center
- **Dynamic QR code display** with scan animation
- **Animated scan line** effect
- Download PNG option
- Copy link to clipboard
- Native share API support

### 💬 Testimonials
- **Auto-scrolling carousel** of review cards
- Client photo, name, company
- Star ratings display
- Auto-advances every 3.5 seconds

### 📊 Analytics Dashboard
- **Animated counters** for:
  - Total Visitors
  - QR Scans
  - Contact Saves
  - Link Clicks
  - Portfolio Visits
- **Circular progress rings** for engagement metrics
- Scroll-triggered animations

### 📧 Contact Hub
- Interactive contact panel with click-to-copy
- Phone, Email, Address, Business Hours
- **Contact form** with floating labels
- Live validation feedback
- **Success animation** on submit

### ⚙️ Settings Panel
- **Dark/Light mode** toggle
- **Animation on/off** toggle
- **Accent color switcher** (4 colors: Ice Blue, Emerald, Lavender, Sunset)
- **Language selector** dropdown
- Real-time preview of changes

### 🎨 Animations & Effects
- **Morphing background blobs** (4 organic shapes)
- **Floating light orbs** with parallax
- **Ripple click** effect on all buttons
- **Cursor glow** following mouse
- **Magnetic buttons** responding to cursor proximity
- **Toast notifications** for user actions
- **Smooth scroll** navigation
- **Card hover lift** animations
- **Status dot pulse** animation
